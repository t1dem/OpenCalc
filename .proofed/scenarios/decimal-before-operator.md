name: Add a decimal point inside an earlier number
target: android
execution: local
device: Pixel_8_API_34
os_version: '14'
paths: [app/src/main/**]
---
1. Tap the keypad buttons 2, ×, 0, the decimal point and 5, so the expression reads 2×0.5.
2. Tap in the expression right after the 2, before the ×, to put the cursor there.
3. Tap the decimal point and then 5.
4. Check that the expression reads 2.5×0.5 and the result below it shows 1.25.
Stop after this check.
